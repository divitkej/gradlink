# Share-card and icon sources

`app/opengraph-image.png`, `app/twitter-image.png` and `app/apple-icon.png` are
static files rendered from the `.tsx` sources in this folder.

They used to be generated by `next/og` routes. Those routes were prerendered at
build time anyway, but importing `next/og` put its image renderer (resvg/yoga
WASM plus a bundled font, ~620 KiB gzipped) into the Cloudflare Worker, which
has a 3 MiB limit on the Workers Free plan. Shipping the PNGs gives identical
link previews for free.

To change a design:

1. Move the `.tsx` back into `app/` and delete the matching `.png` there.
2. `npm run build`
3. Copy `.next/server/app/<name>.body` to `app/<name>.png`, then move the
   `.tsx` back here.
